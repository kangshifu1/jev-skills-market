- **闲鱼词典**：Jev 用于同步脚本的 Noul 噪音复核，默认配置使用 TypeSafe 官方端点；支持配置自托管兼容服务，但本次接入依据是实际托管调用路径。`--ai-review` 启用该步骤，缺凭据或失败时可降级跳过。没有安装扩展、执行词典同步、抓取商品或验证过滤效果。GitHub API 未识别许可证，固定目录树根部及 package.json 未见许可证声明，按链接条目登记，不推断复制或再分发权限。
- **SAG**：设置表单包含 TypeSafe 官方端点；服务将模型配置传入 `zleap-sag==0.15.0` 的 JevConfig，检索入口通过依赖引擎执行 `multi_jev`，连接检查调用 JevClient.score。直接 HTTP 传输位于依赖中，本轮没有安装或运行依赖。配置后需显式选择重排；固定版本文档列出 LanceDB / Elasticsearch 支持、pgvector 不支持该模式。没有部署服务、导入文档、执行连接探测或复现效果、成本和回退行为。
