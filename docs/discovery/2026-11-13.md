## Calibrain Harness

Calibrain Harness 可用 Jev 判断加密永续合约行情，并用后续行情评估预测概率的校准程度。上游将订单执行限定在 Bybit 测试网。 默认使用 Kairos，切换到 Jev 后使用 `jev-1.14.0`，可通过 `CTB_JEV_MODEL` 指定版本。引擎记录模型及概率答案，报告支持查看 Brier 分数和校准误差。新闻预测 `news_return` 属于 Kairos。

上游完整环境使用 Python 3.12、Node.js 20+ 和 Bybit 测试网凭据。选择 Jev 时需配置 TYPESAFE_API_KEY。 Jev 可通过 `CTB_MODEL_PROVIDER=jev` 或终端中的 MODEL 选项启用。本轮仅核对源码，未调用模型、访问交易账户或下单。[上游使用说明](https://github.com/zadescoxp/calibrain-harness/blob/d0f526b06a34e92bf4b45e6e16ecff3ddf9198e1/README.md#L83)
