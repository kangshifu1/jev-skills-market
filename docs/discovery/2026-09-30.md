## 类型和使用范围

- `hyper-jev` 已核实真实 frontmatter 名称、可移植目录和附带客户端；目录命令只安装 Skill 文件，不安装整套教程实验室或 pi 运行时。
- Jev Showcase 按 Python 实验室及 CLI 整体登记；上游另有多个 Skill，其 `jev` 与市场已有 `dbreunig/building-with-jev-skill` 的同名 Skill 来源不同，没有混用 ID 或安装命令。
- 宝可梦项目默认使用 mock，真实模式经 Vercel AI Gateway 调用 Jev；只检查网关适配器，没有运行游戏、下载游戏文件或复现通关成绩。
- JevMeter 先转写再评价句子，叠层反映模型概率，不是事实核查结论；没有读取个人视频或验证上游准确率、速度与费用。
- 系统设计练习使用服务端 TypeSafe 客户端；无凭据时的标识 mock 不作为真实 Jev 接入实测。
- MakerAi 的 Jev 组件通过 Delphi HTTP 客户端发起请求；未编译 Delphi 或将模型判断描述为安全授权。
- Invaders 的 Jev 自动控制器为可选编译功能；本轮仅检查 Go HTTP 客户端和上游说明。
- Emacs llm 的 TypeSafe 提供商和公共决定函数均已读取；本地兼容服务与托管 Jev 保持区分。
