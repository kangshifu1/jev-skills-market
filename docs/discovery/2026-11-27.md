## OmniRoute

AI 网关可选用 TypeSafe Jev 从配置的模型候选中选择请求目标，支持 Jev 组合策略和 System One 决策路由。

固定提交中的 Jev 策略从获准的候选集合构造 Choice 问题，调用 TypeSafe /v1/systemone，检查答案后调整候选顺序。另一路径由 systemone 决策器选择模型，再交给规则选择连接；缺少凭据、低置信度或调用失败时采用对应回退。

仓库拥有者为 cheaper-inference，本次核实时为 90564★，默认分支 release/v3.8.55，最近推送 2026-11-26T23:55:10Z，根许可证 MIT。[固定提交](https://github.com/cheaper-inference/OmniRoute/commit/9671192011beb2d7f83979f40be488c5da8772b9)

- 按上游部署并配置提供商与候选模型；npm 包要求 Node.js >=22.22.2 <23 或 >=24.0.0 <27。
- 使用 jev 组合策略时，需要配置 typesafe 连接并显式开启 COMBO_JEV_STRATEGY_ENABLED。
- 使用 decision 路由的 systemone 决策器时，需要 COMBO_DECISION_ROUTER_ENABLED，以及允许访问的 typesafe 连接；该路径还支持 OMNIROUTE_DECISION_API_KEY 环境变量。
