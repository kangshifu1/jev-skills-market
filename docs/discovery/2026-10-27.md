## 使用范围

- **Pi Web Access**：已读取模型引用、`findOfType` / `classify` 调用和搜索路由分支。需要显式配置 `off-topic` 回退及 Jev 模型，且 Pi 宿主须支持分类模型注册表。只在路由搜索返回内容后检查；指定提供商、all/列表搜索不检查，MCP 因没有注册表也不执行。判断失败或超时保留原回复并写诊断信息，不能视为已验证的严格质量门槛。
- Pi 判断会发送查询、回复及结果标题、URL、摘要给所选提供商。源码列出的阈值和上游校准/延迟数据没有复现；没有安装扩展、读取 Pi 凭据、执行搜索或测试宿主版本兼容性。传输由 Pi 提供商实现，本次不把它描述为本仓库的直接 HTTP 实现。
- **VideoAdGuard**：已读取 TypeSafe 官方预设、provider 分派、字幕 Noul 构建、SDK `systemOne` 调用和代码区间合并。它是浏览器扩展而非通用 Skill；本条核实 TypeSafe 路径，不将其他兼容模型、音频转录或字幕外的能力归给 Jev。
- VideoAdGuard 的 SDK 显式启用 `dangerouslyAllowBrowser`，调用发生在浏览器侧。广告请求包括完整字幕、标题、置顶评论及相关商品信息；凭据由扩展设置提供。这里只记录上游数据流，没有复制或部署这一凭据处理方式，也未读取浏览器配置或访问用户视频。
- 上游用字幕概率阈值合并广告区间，检测准确性、误跳、边界、SDK/浏览器兼容性均未实测。没有安装、构建、播放视频或调用模型。
- Pi Web Access 的 GitHub 许可证识别为 MIT。VideoAdGuard 的 GitHub API 识别为 GPL-2.0，但固定 package.json 明确写 GPL-2.0-or-later；目录保留该声明并在 github 元数据中保留原 API 值，未复制第三方源码。
