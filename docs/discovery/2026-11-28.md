## Pots / pi-durable-bot

自托管聊天助手可通过 pi 的 Jev 分类器判断未提及助手的消息是否与职责相关、是否需要回复，再决定是否唤醒主代理。

机器人根据配置创建 judge，经 pi 的 models.classify 提交职责、近期消息与两个布尔问题。消息调度器检查两个概率；未配置 judge 或判断失败时交由主代理处理，直接提及和私聊另有唤醒路径。

## Telegram Summary Bot

Cloudflare Workers 群聊摘要机器人，通过 Tokener 的 TypeSafe 转发接口调用 jev-latest 判定广告；符合源码阈值的目标群消息会触发删除和发送者封禁。

普通消息和编辑消息的处理入口都会调用审核函数。审核使用文本、说明、实体链接和按钮作为状态，排除受保护的管理员或转发情况，判断失败时保留消息；符合条件时调用 Telegram 删除与封禁接口，并清理对应 D1 记录。

仓库拥有者为 asukaminato0721，本次核实时为 210★，默认分支 master，最近推送 2026-11-02T01:19:20Z，根许可证 Apache-2.0。[固定提交](https://github.com/asukaminato0721/telegram-summary-bot/commit/e253d9481b1bdc3c5f5f6fbd78c53678f5cfa979)

- 需要自部署 Cloudflare Workers、D1 的 DB 绑定、Telegram 机器人凭据及目标群所需管理权限。
- 此版本将 GEMINI_API_KEY 用作 api.tokener.ai/typesafe/v1/systemone 的 Bearer 凭据；这是第三方转发路径，不是 TypeSafe 直连。
