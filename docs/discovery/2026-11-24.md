## Jev-Interaction

语音会话运行时将当前转写和会话状态交给 Jev，用返回的概率控制回应、让出话轮和倾听反馈。回复文本与语音输出由配置的其他适配器完成。 需要 Python 3.10+、jev-interaction 及相应服务端依赖。使用 TypeSafe 后端时配置 JEV_API_KEY，并分别配置语音识别、语言模型和语音合成适配器。 上游提供 jev-interaction[server] 包和 serve 命令，以及库级 Session 示例。JEV_URL、JEV_MODEL 可改变判断服务和模型。实际语音质量、端到端时延及宿主连接尚未实测。 [上游使用说明](https://github.com/native-bond-lab/Jev-Interaction/blob/e963bd69e83d6c884ff899d1e9d2ff35a8125df5/README.md#L53)

Jev 接收的判断状态包括当前转写、会话记录和静默时长。会话策略检查返回结果是否仍适用于当前话轮，再决定下一步。这里仅核实源码调用链，语音录入、服务运行和模型调用均未执行。
