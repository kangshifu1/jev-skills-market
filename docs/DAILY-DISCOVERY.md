# 每日项目发现规则

维护者的 Codex 定时任务每天北京时间 08:00 搜索 GitHub，检查新建或最近更新的
Jev / TypeSafe AI 项目。此任务由维护者本地 Codex 调度，不是本仓库的 GitHub Action。

- 自动收录要求当前 GitHub Star 数 **严格大于 100**，即至少 101。
- 必须从 README、源码或官方文档核实实际 Jev / TypeSafe 集成，不能只匹配名称。
- 排除归档和重复仓库；记录来源提交、检查时间、Star 数和关联证据。
- 区分可安装 Skill、其他工具与资源目录；不虚构接口、安装命令和测试状态。
- 外部项目保持独立，目录推荐不触发执行。未明确授权的第三方源码不复制入库。
- 测试、校验和提交检查通过后，正常提交并 push；有冲突或验证失败则保留现状并报告。
- 没有符合条件的新项目时不创建空提交。

用户明确指定的收录属于人工选择，例如 QuantSkills；不据此声称其符合自动发现门槛。
定时任务的启用状态在维护者 Codex 中管理，克隆本仓库不会自动创建或运行该任务。
